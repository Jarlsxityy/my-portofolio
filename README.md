# Moh. Farras Cesar | Personal Portfolio

A simple, clean, and responsive personal portfolio website built with **HTML**, **CSS**, and a little bit of **JavaScript**. It is published for free using **GitHub Pages**.

This project was created for the **English for Informatics Engineering** video project: *How to Create a Landing Page Using GitHub*.

## Live Demo

**https://jarlsxityy.github.io/test-project/**

## Features

- **Navigation menu** with smooth scrolling to each section
- **Hero section** with a headline, a short description, and call-to-action buttons
- **Dark and light theme** toggle (the choice is saved in the browser)
- **About, Skills, Projects, and Contact** sections
- **Responsive design** that works on desktop, tablet, and mobile (with a hamburger menu)
- **Scroll animation** (fade-in effect) for each section
- **Clean blue and black design** with a subtle developer style

## Technologies Used

## How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Jarlsxityy/test-project.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

No installation or build tools are needed.

## How to Publish with GitHub Pages

1. Upload `index.html`, `style.css`, and the `assets` folder to the repository root.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the **main** branch and the **/ (root)** folder, then click **Save**.
5. Wait one to three minutes, then open the published URL.
